오늘 실습을 하며 스쳐 간 낱말들을 모았다. 배운 순서대로 늘어놓을까 했는데, 읽어 보니 **순서보다 주제로 이어지는 쪽이 더 컸다.** 예를 들어 SDK와 uv는 따로 배운 말이지만 같은 연장통이고, RAG와 Query는 검색이라는 한 동작의 안팎이다. 그래서 네 갈래로 묶었다.

## 갈래 1. 모델을 부리는 도구와 손놀림

### 1. SDK(Software Development Kit)
- **정의**: 특정 서비스를 쉽게 개발하도록 **묶어 제공하는 도구 모음**(라이브러리·설명서·예제).
- **비유**: **가구 조립 키트**. 판재·나사·육각렌치·설명서가 한 상자에 담겨 온다.
- **예시**: 오늘 만진 Claude Agent SDK와 LangChain이 SDK다. 같은 일도 SDK마다 사용법과 기본값(타임아웃 등)이 달랐다.

### 2. uv
- **정의**: 파이썬의 **패키지 설치·가상환경·실행을 빠르게 관리**하는 도구. `uv init`(프로젝트 생성)·`uv venv`(가상환경)·`uv add`(설치)·`uv run`(실행).
- **비유**: **전동 공구**. 손으로 하나씩 조이던 일을 한 도구로 빠르게 처리한다.
- **예시**: 오늘은 pip로 패키지를 깔았는데, uv면 `uv add`로 같은 일을 더 빠르게 한다.

### 3. 템플릿(Template)
- **정의**: 내용만 갈아 끼워 **반복해서 쓰도록 미리 만들어 둔 틀**.
- **비유**: **붕어빵 틀**. 틀은 그대로 두고 팥·슈크림만 바꿔 굽는다.
- **예시**: 오늘 실습의 프롬프트가 그랬다. 질문은 고정하고 system 지시(정중한 톤·기술 톤)만 갈아 끼웠다.

### 4. 문자열화(Stringify)
- **정의**: 숫자나 객체 같은 데이터를 **문자(String) 형태로 바꾸는 것**.
- **비유**: 계산기 화면의 값을 **공책에 글자로 옮겨 적기**. 머릿속 숫자를 종이에 받아 적는 일.
- **예시**: 오늘 모델 응답(객체)을 파일로 저장할 때, 그 내용을 문자로 바꿔 기록했다.

## 갈래 2. 자료를 찾아 보태기

### 5. RAG(Retrieval-Augmented Generation)
- **정의**: 답하기 전에 **관련 자료를 먼저 검색**해 와서, 그 자료를 근거로 모델이 답을 만들게 하는 방식. 검색(Retrieval)으로 생성(Generation)을 보강(Augmented)한다는 뜻.
- **비유**: **오픈북 시험**. 문제를 받고 무작정 쓰는 게 아니라, 관련 페이지를 펼쳐 놓고 보며 답을 쓴다.
- **예시**: 옵시디언 노트에서 질문과 가까운 조각만 찾아 넣는 개인 검색 실습이 이 구조였다. 검색이 엉뚱한 걸 집으면 답도 같이 틀어진다.

### 6. Query(쿼리)
- **정의**: 데이터나 정보를 **요청·검색하려고 넣는 질문이나 명령**.
- **비유**: 식당 **주문서**. 원하는 걸 적어 내밀면 그에 맞춰 나온다.
- **예시**: RAG에서 검색에 쓰는 질문이 query다. 이 문장을 좌표로 바꿔 가까운 조각을 찾는다.

## 갈래 3. 만들기 전에 정하고 지킬 것

### 7. PRD(Product Requirements Document)
- **정의**: **무엇을·왜 만들고 어떤 기능이 필요한지** 정리한 제품 요구사항 문서.
- **비유**: 집 짓기 전 **설계도**. 벽돌을 쌓기 전에 방 개수와 용도를 먼저 정한다.
- **예시**: 서비스를 시작할 때 코드보다 먼저 "누구를 위해 무슨 기능을 왜"를 적어두는 문서다.

### 8. .env
- **정의**: API 키·비밀번호 같은 **환경변수를 코드 밖에 따로 보관하는 파일**. 보통 `.gitignore`에 등록해 GitHub에 올라가지 않게 한다.
- **비유**: **열쇠는 현관 매트 밑이 아니라 금고에**. 열쇠(비밀값)를 문(코드)에 붙여두지 않는다.
- **예시**: 봇 토큰이나 API 키를 코드에 직접 쓰면 저장소에 그대로 노출된다. `.env`로 빼고 `.gitignore`에 넣는 게 기본이다.

## 갈래 4. 서버가 돌려주는 신호

### 9. 401 오류(Unauthorized)
- **정의**: **인증 정보가 없거나 틀려서** 서버가 요청을 거부하는 오류. 401 = 인증 문제.
- **비유**: 출입증 없이 문 앞에 선 상황. **"당신이 누군지 확인이 안 됨"** 이라 못 들어간다.
- **예시**: API 키나 토큰이 틀리면 401이 뜬다. 클라우드 모델 호출이 막히면 키부터 확인.

### 10. 503 오류(Service Unavailable)
- **정의**: 서버가 **지금은 요청을 처리할 수 없는 상태**. 과부하·점검·일시 장애가 원인. 503 = 서버 쪽 문제.
- **비유**: 가게 문에 걸린 **"잠시 영업 중단"** 팻말. 가게는 있는데 지금은 손님을 못 받는다.
- **예시**: 클라우드 모델에 요청이 몰릴 때 503이 뜬다. 내 키 문제(401)와 달리, 잠시 뒤 재시도가 답일 때가 많다.

---

배운 순서로 늘어놓았으면 열 줄짜리 목록이었을 텐데, 갈래로 묶으니 낱말들이 서로 어디서 만나는지가 보인다. SDK와 uv가 같은 연장통이고, RAG와 Query가 검색이라는 한 동작의 안팎이고, 401과 503이 나란히 서버의 대답이라는 것. 용어는 외우는 게 아니라 이렇게 자리에 놓일 때 내 것이 된다.
